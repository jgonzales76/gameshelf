Simple collection updates

Import collection exports manually, with optional automatic synchronization if API access is approved.

Planned BoardGameGeek integration

The proposed integration is for a single household's personal board-game collection. If API access is approved, a Raspberry Pi backend will make read-only requests to BoardGameGeek's XML API to retrieve collection and game metadata such as BGG IDs, game names, cover image references, player counts, play times, ratings, complexity, and game mechanics.

  • Noncommercial and not monetized; no public user accounts or paid service.
  • Server-side API requests, with appropriate caching and conservative sync intervals.
  • BoardGameGeek data used to display the owner's collection privately in a home.
  • Manual XML/CSV collection imports remain available without API integration.
  • API use and artwork handling will follow any applicable BoardGameGeek licensing terms.

Status: Application under development. API integration is proposed, not implemented or approved yet.
